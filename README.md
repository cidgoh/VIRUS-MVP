# Segmenting the heatmap

This branch demonstrates the potential to eventually load discrete heatmaps for
individual sections of a genome. Such functionality could be useful for public
health practitioners seeking a more "compact" view of a single gene, as opposed
to a whole genome representation that may be more "information-dense" or
time-consuming to navigate. In addition, this functionality would provide a
more intuitive representation of naturally segemented genomes
visualizing segmented genomes, such as influenza.

This branch is a work-in-progress.
